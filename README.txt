VORTEXUS 26 — GITHUB PAGES + FIREBASE

Website kenangan VORTEXUS 26 dengan login kelas, upload foto/video, filter jurusan, dan panel admin online.

Versi GitHub Pages sebelumnya menyimpan upload di IndexedDB sehingga foto hanya muncul pada browser yang mengupload. Versi ini memakai Firebase untuk penyimpanan bersama: Firebase Authentication + Firestore + Cloud Storage.

Lihat firebase-setup.txt dan README-GITHUB-PAGES.txt sebelum deploy.
